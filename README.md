## 프로젝트명
HowMuch Homes 부동산·주택 구매 가능성 분석 플랫폼

## 수행 시기
2022년

## 프로젝트 소개
사용자의 자산 및 대출 조건을 기반으로 구매 가능한 주택을 탐색하고, 지도에서 아파트 및 부동산 정보를 확인할 수 있도록 개발한 부동산 정보 서비스.

사용자가 자기자본, 대출 비율, 주택 보유 여부, 거래 유형, 희망 지역 등의 조건을 설정하면 해당 조건을 기반으로 거래 가능한 매물을 조회하고 지도와 목록 형태로 제공한다.

대량의 부동산 데이터를 지도에서 효율적으로 조회할 수 있도록 현재 지도 화면에 표시되는 영역을 기준으로 데이터를 요청하는 방식으로 구성하였다.

## 주요 기술
- Vue.js 2
- JavaScript
- Vuex
- Vue Router
- Axios
- Naver Maps
- vue-naver-maps
- MariaDB
- REST API
- HTML / SCSS

※ 백엔드 서비스 자체는 Node.js / Express 기반으로 구성됨.

## 주요 기능

### 사용자 조건 설정
- 거래 유형 설정
- 주택 보유 여부 설정
- 자기자본 입력
- 대출 비율 설정
- 희망 지역 설정
- 사용자의 자금 조건에 따른 주택 조회

### 지도 기반 부동산 조회
- Naver Maps 기반 부동산 지도 구현
- 아파트 위치 Marker 표시
- 지도 이동 및 확대/축소 처리
- 지도 중심 좌표 관리
- 현재 지도 영역에 포함되는 아파트 조회
- 지도와 매물 목록 화면 연동
- 아파트 선택 및 상세화면 이동
- 지역 검색 및 지도 위치 이동

### 지도 데이터 최적화
대량의 부동산 데이터를 한 번에 지도에 표시하지 않고 현재 사용자가 보고 있는 지도 영역을 기준으로 필요한 데이터를 요청하도록 구성하였다.

지도 Bounds에서 다음 좌표를 계산하여 API 조회 조건으로 전달하였다.

- Left
- Right
- Top
- Bottom

이를 통해 현재 화면 범위에 포함되는 아파트 데이터만 조회하여 Marker로 표시하도록 구현하였다.

또한 Zoom Level에 따라 Marker 조회 여부를 제어하여 넓은 지역에서 불필요하게 많은 데이터를 요청하거나 렌더링하지 않도록 구성하였다.

## DB 설계
대량의 부동산 및 사용자 데이터를 서비스에서 활용할 수 있도록 데이터베이스 구조를 설계하였다.

주요 데이터 영역:
- 사용자
- 사용자 자산 및 대출 조건
- 지역정보
- 아파트
- 아파트 매물
- 가격 및 면적정보
- 관심 매물
- 검색 기록
- 리뷰
- 문의
- 공지사항 및 FAQ
- 사용자 설정

서비스 화면과 기능에서 필요한 데이터 관계를 정의하고 이를 기반으로 ERD 및 DB 구조를 설계하였다.

- REST API 연동

- ERD 설계
- 대량 부동산 데이터를 서비스에서 활용하기 위한 데이터 구조 설계

## 프로젝트 내 역할
프로젝트에서 일반 Backend API 및 Stored Procedure 개발을 제외한 사용자 Frontend와 DB 설계를 담당하였다.

Vue.js와 Naver Maps를 기반으로 사용자가 자산 및 대출 조건에 맞는 주택을 지도에서 탐색할 수 있는 사용자 서비스를 구현하였다.

특히 대량의 부동산 데이터를 지도에 모두 표시할 경우 발생할 수 있는 조회 및 렌더링 부하를 줄이기 위해 현재 지도 화면의 Bounding Box와 Zoom Level을 기준으로 필요한 데이터만 조회하고 Marker로 표시하는 구조를 적용하였다.

또한 서비스에서 사용하는 사용자·지역·아파트·매물·가격·리뷰 등의 데이터 관계를 정의하고 전체 DB 구조 및 ERD를 설계하였다.

Node.js 기반 Backend API와 Stored Procedure 구현은 다른 개발자가 담당하였다.
